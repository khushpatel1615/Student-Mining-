# Student Data Mining - Enterprise Dashboard

A comprehensive university management system with role-based access, real-time analytics, AI-powered insights, and intelligent student performance tracking.

## 🚀 Key Features
- **Admin Dashboard**: Real-time analytics, Risk Center, Grade & Attendance Management, and AI Chat Assistant.
- **Student Portal**: Personalized dashboards, enrollment tracking, grade/attendance viewing, and assignment submissions.
- **Teacher Tools**: Grade and attendance management, assignment creation, and performance tracking.

## 🛠️ Tech Stack
- **Frontend**: React 18, Vite, Context API, Chart.js, Framer Motion
- **Backend**: PHP 8.1+, MySQL 8.0+, JWT Authentication
- **AI/Analytics**: Google Gemini API for administrative insights
